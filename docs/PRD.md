# 프로젝트 명: DocuFit (관공서 제출용 서류 이미지 최적화 툴)
# Product Requirements Document (PRD)

## 1. 프로젝트 개요
관공서, 은행 등 보수적인 웹사이트의 첨부파일 제한(용량 제한, 특정 확장자만 허용)으로 인해 불편함을 겪는 사용자들을 위한 웹 기반 이미지 최적화 및 편집 툴입니다. 회원가입 없이 누구나 즉시 사용할 수 있어야 합니다.

## 2. 기술 스택
- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes (or Express.js)
- **Image Processing:** 
  - Frontend: `heic2any` (아이폰 HEIC 처리), `Fabric.js` (또는 HTML5 Canvas API를 이용한 에디터 구현)
  - Backend: `sharp` (용량 최적화 및 리사이징)
- **Database & Storage:** PostgreSQL (Prisma or Supabase), AWS S3 (또는 호환 Object Storage)

## 3. 핵심 기능 요구사항

### 3.1. 확장자 및 포맷 변환 (Format Conversion)
- 사용자가 업로드한 모든 형태의 이미지를 지원.
- 특히 **아이폰 카메라의 HEIC/HEIF 포맷을 완벽하게 대응**해야 함 (클라이언트 단에서 변환하여 서버 부하 감소 권장).
- 최종 다운로드 포맷은 사용자가 선택 가능 (JPG, PNG, PDF). 여러 장을 합쳤을 경우 하나의 PDF로 내보내는 기능 필수.

### 3.2. 목표 용량 맞춤 최적화 (Target Size Compression)
- 사용자가 원하는 최종 파일 용량(예: 5MB, 10MB, 20MB 이하)을 입력 또는 슬라이더로 선택.
- 백엔드(sharp)에서 목표 용량에 맞춰 이미지의 해상도와 Quality를 반복 조절하여 최적화된 파일을 생성.

### 3.3. 다중 이미지 이어붙이기 (Stitching) & 캔버스 레이아웃
- 여러 장의 이미지(예: 임대차계약서 1~3페이지)를 업로드하면 하나로 이어붙이는 기능.
- **정렬 옵션:** 세로로 이어붙이기(위에서 아래), 가로로 이어붙이기(왼쪽에서 오른쪽).
- **드래그 앤 드롭:** 캔버스 상에서 사용자가 자유롭게 이미지를 배치하고 순서를 변경할 수 있는 기능.

### 3.4. 이미지 에디터 기능 (Redaction & Editing)
- 주민등록번호, 서명 등 민감한 개인정보를 가릴 수 있는 **블랙박스(검은색 칠하기) 및 모자이크/블러 브러쉬 기능**.
- 불필요한 배경을 잘라낼 수 있는 **크롭(Crop) 기능**.

### 3.5. 스토리지 및 DB 연동 (업로드/다운로드)
- 업로드된 원본 이미지 및 편집된 결과물은 AWS S3에 저장.
- DB에는 파일의 메타데이터(S3 URL, 파일 크기, 생성 시간, 익명 세션 ID)를 저장.
- 사용자는 최종 변환된 파일을 클릭 한 번으로 로컬에 다운로드 가능.

### 3.6. 🔒 보안 및 데이터 파기 (Privacy - Critical)
- 회원가입 없이 민감한 서류를 다루므로, 개인정보 보호가 최우선.
- **TTL (Time To Live) 로직 적용:** S3에 업로드된 파일 및 DB 레코드는 **생성 후 1시간이 지나면 무조건 자동 삭제**되도록 스케줄러(Cron job) 또는 S3 Lifecycle Rule을 구성해야 함.

## 4. 클로드 코드를 위한 개발 단계(Phase) 지시

- **Phase 1: 초기 설정**
  - Next.js 프로젝트 세팅 (TypeScript, Tailwind).
  - AWS S3 업로드 유틸리티 및 DB 스키마(Prisma 등) 작성.
- **Phase 2: 프론트엔드 핵심 UI 및 에디터 구현**
  - 파일 드래그 앤 드롭 업로드 UI 생성 (heic2any 통합).
  - Fabric.js(또는 캔버스)를 활용한 이미지 이어붙이기, 크롭, 가리기(Masking) UI 구현.
- **Phase 3: 백엔드 이미지 프로세싱**
  - 프론트에서 편집된 데이터/이미지를 받아 `sharp`를 이용해 목표 용량에 맞게 압축하는 API 엔드포인트 구현.
  - PDF 변환 유틸리티 작성.
- **Phase 4: 마무리 및 다운로드 플로우**
  - 결과물을 S3에 저장하고 다운로드 링크를 프론트에 반환.
  - 1시간 뒤 데이터 자동 삭제(Cleanup) 로직 구현.
